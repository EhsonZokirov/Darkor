Каталог блогеров Таджикистана: поиск, фильтры, профили авторов, заявки на рекламу и форма добавления блогера.


Стек: React 19, Vite, React Router, react-icons.

## Запуск

```bash
npm install
npm run dev      # режим разработки
npm run build    # сборка в папку dist
npm run preview  # просмотр собранного сайта
npm run lint     # проверка кода
```

## Что менять и где

| Что | Где |
| --- | --- |
| Название, e-mail, Instagram, адрес формы, категории | `src/config.js` |
| Ключи базы данных | `.env` (образец в `.env.example`) |
| Структура базы и права доступа | `supabase/schema.sql` |
| Список блогеров | `src/data/bloggers.js` |
| Фото блогеров | `src/images/` |
| Цвета, шрифты, анимации | `src/index.css` (переменные в начале файла) |

### Добавить блогера

В `src/data/bloggers.js` скопируйте любой объект, поставьте новый `id`, импортируйте фото из `src/images/` и заполните поля.
Поле `city` — это город блогера (например, «Душанбе»).

## Как работают формы

Формы «Добавить блогера», «Заказать рекламу» и «Контакты» проверяют поля и отправляют заявку одним из двух способов:

1. **Если в `src/config.js` указан `FORM_ENDPOINT`** (например, адрес на [Formspree](https://formspree.io)), заявка уходит туда POST-запросом в формате JSON.
2. **Если `FORM_ENDPOINT` пуст**, открывается письмо в почтовой программе пользователя с уже заполненным текстом (`mailto:`). Заявка также сохраняется в браузере пользователя.

Чтобы заявки приходили автоматически, без участия пользователя, создайте форму на Formspree и вставьте её адрес в `FORM_ENDPOINT`.

## Бэкенд (Supabase)

Без бэкенда сайт работает как витрина: каталог берётся из `src/data/bloggers.js`, а формы отправляют заявки письмом.
С подключённым [Supabase](https://supabase.com) (есть бесплатный тариф) появляется:

- регистрация и вход блогеров (почта и пароль);
- личный кабинет: блогер сам заполняет анкету, загружает фото и правит её;
- модерация: новая или изменённая анкета попадает в каталог только после одобрения администратором;
- админ-панель `/admin`: одобрить, отклонить или удалить анкету, читать заявки на рекламу и сообщения с сайта;
- заявки на рекламу и сообщения из формы «Контакты» сохраняются в базе.

Блогеры из `bloggers.js` продолжают показываться в каталоге вместе с блогерами из базы.

### Как подключить

1. Создайте проект на [supabase.com](https://supabase.com).
2. Откройте **SQL Editor**, вставьте весь файл `supabase/schema.sql` и нажмите **Run**. Он создаёт таблицы, права доступа и хранилище для фото. Файл можно запускать повторно.
3. Скопируйте `.env.example` в `.env` и впишите адрес проекта и ключ `anon` (**Project Settings → API**).
4. Выполните `npm install` и `npm run dev`.
5. Зарегистрируйтесь на сайте (кнопка «Войти»), затем в **SQL Editor** назначьте себя администратором:

   ```sql
   update public.profiles
      set role = 'admin'
    where id = (select id from auth.users where email = 'ваша@почта.com');
   ```

   После этого в меню появится пункт «Админ».

### Важно

- **Подтверждение почты.** По умолчанию Supabase просит подтвердить почту после регистрации. Для проверки можно отключить: **Authentication → Providers → Email → Confirm email**. Для настоящего сайта лучше оставить включённым.
- **Ключ `anon` публичный**, он попадает в браузер, и это нормально: данные защищены правилами доступа (Row Level Security) из `schema.sql`. А вот ключ `service_role` нельзя вставлять ни в `.env`, ни в код сайта.
- **Публикация на Netlify.** Добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` в **Site settings → Environment variables** и пересоберите сайт.
- **Адреса для входа.** В Supabase в **Authentication → URL Configuration** укажите адрес вашего сайта, иначе ссылки из писем подтверждения будут вести не туда.

## Публикация

Сайт — одностраничное приложение. Файл `public/_redirects` уже настроен для Netlify, чтобы прямые ссылки (например, `/blogger/3`) открывались корректно. На другом хостинге включите перенаправление всех адресов на `index.html`.
